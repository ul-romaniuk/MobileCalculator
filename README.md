# Калькулятор

Простий мобільний калькулятор на Python і Kivy. Підтримує арифметичні та унарні операції, історію обчислень і світлу/темну теми.

## Запуск

Потрібні Python 3.10 або новіший. Встановіть залежності й запустіть з кореня проєкту:

```sh
python -m pip install -r requirements.txt
python app/main.py
```

Параметри назви, версії, опису та відомостей про розробника задаються у `.env`. Файл `.env` не додається до Git; скопіюйте `.env.example` у `.env` і змініть потрібні значення. Якщо `.env` відсутній, `app/config.py` використовує зрозумілі заглушки (наприклад, «Група») замість конкретних даних. Налаштування завантажуються класом `Settings` з `pydantic-settings`.

Для Android APK використовується Buildozer. У `buildozer.spec` вкажіть серед залежностей `python3,kivy,pydantic,pydantic-settings` та включіть `.env` у `source.include_patterns`, якщо потрібні налаштування, відмінні від типових. Перед Android-збиранням перевірте наявність рецептів pydantic і pydantic-settings у версіях Buildozer/python-for-android вашого середовища: pydantic-settings залежить від pydantic-core, для якого підтримка Android може відрізнятися. Якщо рецепти недоступні, заміна — `dataclass` для типізованих налаштувань разом із `python-dotenv` для `.env`; це прибирає pydantic-валідацію та залежність від pydantic-core, але потребує власного завантаження й перевірки значень. Типові значення при цьому можна зберегти.

## Тести

```sh
python -m pytest
```

## Структура

- `app/config.py` — налаштування, константи й відомості екрана «Про розробника».
- `app/models/` — стан калькулятора.
- `app/controllers/` — обробка дій користувача.
- `app/operations/` — арифметика, винятки, унарні операції та форматування.
- `app/storage/` — історія, налаштування та JSON-файли.
- `app/ui/` — Kivy-екрани, віджети, теми й піктограми.
- `tests/` — тести обчислювача.

`app/main.py` створює моделі та контролер, підключає їх до Kivy-екранів і координує навігацію. Дані застосунку зберігаються у внутрішній папці даних Kivy.
