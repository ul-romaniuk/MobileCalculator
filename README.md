## Опис

Застосунок надає графічний інтерфейс калькулятора для мобільного пристрою. Вираз формується натисканням клавіш, обчислюється з урахуванням пріоритетів операцій, а результат показується у компактному форматі. Окремі екрани дають змогу переглядати й очищати історію та читати відомості про проєкт.

## Можливості

- Додавання, віднімання, множення, ділення та піднесення до степеня.
- Унарні операції: квадрат, квадратний корінь, обернене число, зміна знака та відсоток.
- Обробка десяткової крапки або коми, Unicode-знаків множення, ділення й мінуса.
- Дотримання пріоритету арифметичних операцій; степінь є правоасоціативним.
- Компактне форматування результатів із переходом до наукового запису для великих і малих значень.
- Історія останніх обчислень (до 10 записів за замовчуванням), повторне завантаження виразу або результату та очищення історії.
- Світла й темна теми зі збереженням вибору.
- Екрани калькулятора, історії та відомостей про проєкт; навігація системною клавішею повернення.
- Звичайна й розширена розкладки клавіш.

## Технологічний стек

- **Python** — логіка застосунку та тести.
- **Kivy 2.3.1 або новіший** — графічний інтерфейс і запуск застосунку.
- **`decimal.Decimal`** зі стандартної бібліотеки Python — арифметичні обчислення.
- **pytest** — автоматизовані тести (потрібно встановити окремо; до `requirements.txt` не включений).
- **Buildozer** і **python-for-android** — конфігурація пакування для Android у `buildozer.spec`.

## Архітектура

Код розділено за ролями у стилі MVC:

- **Model:** `CalculatorModel` зберігає поточний вираз і стан дисплея та делегує обчислення класу `Calculator`. `History`, `Settings` і `JsonFile` відповідають за дані, що зберігаються між запусками.
- **View:** Kivy-екрани калькулятора, історії та відомостей, спільні віджети й описи тем. Подання створюють інтерфейс і передають дії через зареєстровані callback-функції.
- **Controller:** `CalculatorController` перетворює натискання клавіш на зміни моделі, а `ApplicationController` з'єднує подання та модель, обробляє навігацію, історію й тему.
- **Composition root:** `CalculatorApp` у `app/main.py` створює сховища, моделі, екрани та контролери, додає екрани до `ScreenManager` і запускає Kivy.

```text
.

│   ├── controller/

│   │   ├── operations/              # Операції, парсер, форматування та винятки
│   │   └── storage/                 # JSON, історія та налаштування теми

│       ├── history_screen.py        # Екран історії
│       ├── about_screen.py          # Екран відомостей
│       ├── widgets.py               # Спільні Kivy-віджети
│       ├── theme.py                 # Кольори й стилі тем

├── pytest.ini                       # Шляхи імпорту для pytest
└── icon.png                         # Іконка застосунку для пакета
```

## Встановлення та запуск

Потрібен Python із підтримкою синтаксису Python 3.10 або новішого та середовище, де доступний Kivy. На настільних платформах Kivy-вікно початково має розмір 400 × 720.

Рекомендовано створити віртуальне середовище:

```sh
python -m venv .venv
```

Активуйте його у відповідній для вашої оболонки формі, після чого встановіть залежність і запустіть застосунок із кореня репозиторію:

```sh
python -m pip install -r requirements.txt
python app/main.py
```

`requirements.txt` містить `kivy>=2.3.1`. Налаштування за замовчуванням визначені в `app/config.py`; файл `.env` проєктом не використовується.

## Збірка для Android

Файл `buildozer.spec` задає назву пакета «Калькулятор», версію `1.2.4`, портретну орієнтацію, `arm64-v8a`, мінімальний Android API 24 і залежності `python3,kivy`. Для збірки потрібні Buildozer та Android SDK/NDK із залежностями, необхідними Buildozer і python-for-android. Buildozer може завантажувати інструменти під час першої збірки.

Установіть Buildozer у підготовленому середовищі розробки, потім із кореня проєкту запустіть debug-збірку:

```sh
buildozer android debug
```

Зібраний APK Buildozer розміщує в каталозі `bin/`. Конфігурація також визначає Android API 36 і NDK 29. Підписання релізу, окремі команди для iOS та інструкція з підготовки SDK/NDK у цьому репозиторії не описані.

## Тестування

Встановіть pytest і запустіть набір тестів із кореня проєкту:

```sh
python -m pip install pytest
python -m pytest
```

Тести в `tests/` перевіряють арифметичний парсер та форматування, контролер калькулятора, модель, керування застосунком і переходами між екранами, подання та теми, історію й JSON-сховище. Перевірки для подань використовують Kivy-віджети.

## Технічні рішення

- **Обчислення:** `Calculator` розбирає плоский вираз на числа й оператори та виконує операції за пріоритетом. Підтримуються `+`, `-`, `*`, `/`, `^`; дужки та довільні функції в парсері не реалізовані. Операції інкапсульовані у класах `BinaryOperation` і `UnaryOperation`.
- **Числова точність і вигляд:** внутрішні значення представлені `Decimal`. `app/config.py` задає точність форматування, граничну довжину дисплея та пороги наукового запису.
- **Помилки:** доменні помилки мають окремі типи для некоректного виразу, ділення на нуль, від'ємного аргументу квадратного кореня та інших збоїв обчислення. Контролер передає текст помилки в стан дисплея.
- **Збереження:** історія та вибрана тема зберігаються як JSON у каталозі даних користувача Kivy, а не в каталозі проєкту. Відсутній або пошкоджений файл читання трактує як значення за замовчуванням. Запис виконується через тимчасовий файл із подальшою заміною цільового.
- **Історія:** записи впорядковані від найновішого; некоректні елементи відкидаються, а кількість обмежується `history_limit` у конфігурації.
