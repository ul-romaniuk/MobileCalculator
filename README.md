# Мобільний калькулятор

Курсовий проєкт з дисципліни «Програмування мобільних платформ». Застосунок створений на Python і Kivy та призначений для Android.

## Можливості

- базові арифметичні операції, степінь і унарні функції;
- форматування великих і малих чисел;
- історія обчислень із повторним використанням виразів;
- світла й темна теми;
- екран із відомостями про проєкт і розробника.

## Архітектура

Проєкт організований за MVC:

- `app/model/` — стан, обчислення, історія та збереження;
- `app/view/` — Kivy-екрани й віджети;
- `app/controller/` — обробка дій і координація моделі з поданнями;
- `app/config.py` — налаштування застосунку;
- `app/main.py` — створення та з'єднання компонентів.

## Запуск

Потрібен Python 3.10 або новіший. Встановіть залежності й запустіть застосунок із кореня проєкту:

```sh
python -m pip install -r requirements.txt
python app/main.py
```

Параметри проєкту можна задати у `.env`. Для початку скопіюйте `.env.example` у `.env` і за потреби змініть значення. `.env` не додається до Git. Якщо файла немає, застосунок використовує типові значення з `app/config.py`.

## Тести

Встановіть pytest для перевірок і запустіть повний набір командою:

```sh
python -m pip install pytest
python -m pytest
```

Тести покривають арифметичні й унарні операції, введення з клавіатури, сценарії контролерів, історію, JSON-сховище, налаштування тем і конфігурацію.

## Android APK

Для збирання APK встановіть Buildozer, створіть конфігурацію командою `buildozer init` і додайте до `requirements` Python-залежності проєкту: `python3,kivy,pydantic-settings`. Збирання:

```sh
buildozer android debug
```

Якщо Android-збірка не підтримує `pydantic-settings`, запасний варіант — `dataclass` із `python-dotenv`; завантаження та перевірку значень тоді потрібно реалізувати окремо.
